# Breast Cancer Classification

## a. Problem statement

Build and compare five classification models that predict whether a breast
mass is malignant or benign from measurements computed from digitized fine
needle aspirate images.

## b. Dataset description

The project uses the official [UCI Breast Cancer Wisconsin (Diagnostic)
dataset](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic).
The downloaded raw data is in `data/wdbc.data`; `data/wdbc.csv` contains the
same 569 instances with feature headers and numeric labels. It has 30 numeric
features and two target classes:
malignant (label 0) and benign (label 1). The feature measurements describe
cell nuclei, including radius, texture, perimeter, area, smoothness, and
related statistics. This exceeds the assignment minimum of 12 features and
500 instances.

The training script makes one stratified 80/20 split with random state 42 and
uses it for every model. Scaling is included in the saved pipelines for
Logistic Regression, KNN, Naive Bayes, and SVM; the Decision Tree uses the
unscaled numeric features.

## Run locally

```bash
python -m pip install -r requirements.txt
python source/train_models.py
streamlit run app.py
```

**Live Streamlit app:** [https://mlassignmnent2-erk8i5qsrrez4q4q9xsxmc.streamlit.app/](https://mlassignmnent2-erk8i5qsrrez4q4q9xsxmc.streamlit.app/)

The training script creates five `.joblib` files in `model/`, data `wdbc.csv`  
files in `data/`, and the shared test data held-out `test_data.csv`. 

## Use the Streamlit app

The app loads the five saved models and defaults to the bundled `test_data.csv`.
You can optionally upload a CSV containing evaluation/test rows only; training
data is not uploaded. The CSV must include the same 30 feature columns as
`data/wdbc.csv` plus a numeric `target` column (`0` = malignant, `1` = benign).
Both target classes must be present to calculate AUC.

Choose a classifier from the dropdown to view its six evaluation metrics,
confusion matrix, and classification report. Expand **Compare all classifiers**
to compare the metrics for all five models on the same uploaded or bundled test
data.


Model artifacts: `logistic_regression.joblib`, `decision_tree.joblib`,
`knn.joblib`, `naive_bayes.joblib`, and `support_vector_machine.joblib`.
